**VERDICT: REQUEST CHANGES**

Required changes:

1. **Correct the colour contract** ([proposal:191](/Users/dii/git/typst.mbt/docs/edsl-ports.md:191)). For a percentage argument `p`, ordinary transparentization is `α × (1−p/100)`, with upstream clamping and different negative-factor behaviour. `lighten`/`darken` also require engine `Ratio` values. Define `mix`’s weight conversion into colour-weight pairs. Engine spaces are constructor values—`rgb`, `luma`, `cmyk`, `oklab`, `oklch`, `color.linear-rgb`, `color.hsl`, `color.hsv`—or a spot colorant, not strings; a string facade needs explicit mapping. Upstream’s default is `auto`, retaining a common spot colorant and otherwise choosing Oklab ([wrappers:16356](/Users/dii/git/typst.mbt/library/funcs_gen.mbt:16356), [color:1241](/Users/dii/git/typst.mbt/library/color.mbt:1241), [color:1790](/Users/dii/git/typst.mbt/library/color.mbt:1790), [color:2041](/Users/dii/git/typst.mbt/library/color.mbt:2041), [color:2110](/Users/dii/git/typst.mbt/library/color.mbt:2110)). Remove general CSS equivalence: Typst averages channels without alpha premultiplication, whereas [CSS requires it](https://www.w3.org/TR/css-color-4/#interpolation-alpha); unequal-alpha mixtures differ ([color:707](/Users/dii/git/typst.mbt/library/color.mbt:707)).

2. **Make fixed Canvas explicitly unbreakable.** `Block` defaults to `breakable=true`, and a fixed height is distributed across regions. The promised single coordinate system therefore does not follow from the stated expansion ([default:698](/Users/dii/git/typst.mbt/library/elems_gen.mbt:698), [flow_block:334](/Users/dii/git/typst.mbt/layout/flow_block.mbt:334)). Also correct §6’s “its elements take no fixed heights”: Canvas explicitly does.

3. **Finish the lint contracts.** L2 must resolve **each glyph’s span**, not “the item’s origin”: text items can combine multiple origins ([grouping:575](/Users/dii/git/typst.mbt/layout/inline_shaping.mbt:575)). L3 cannot guarantee an origin for every offending item: decorations carry detached spans ([inline_deco:23](/Users/dii/git/typst.mbt/layout/inline_deco.mbt:23)). Permit unknown/ancestor origins; exact attribution would require additional engine provenance instrumentation. L4 must distinguish logical occurrences from repeated measurement/layout lowering—callback results are lowered on each invocation, while revision 8 permits arbitrary invocation counts ([session:152](/Users/dii/git/typst.mbt/doc/session.mbt:152), [design:1328](/Users/dii/git/typst.mbt/docs/edsl-design.md:1328)). Raw lowering counts do not establish review ambiguity.

4. **Define placeholders inside code marks and link destinations.** For example, backticks enclosing `\{Emph("x")}` cannot simultaneously preserve that description and lower the whole marked region to `raw("…")`: `Raw` accepts a string, and leaked placeholders are errors ([Raw:4632](/Users/dii/git/typst.mbt/doc/elements_gen.mbt:4632), [prose:121](/Users/dii/git/typst.mbt/doc/prose.mbt:121)). Specify rejection, literal treatment, or another exact expansion.

5. **Supply the kit provenance mechanism claimed by §11.6.** Only Para actually specifies “one site”. `doc/kit` cannot access `doc`’s private `Node`, `Site`, or argument mapping ([content:23](/Users/dii/git/typst.mbt/doc/content.mbt:23)). Specify a public composition hook or another implementation arrangement, including caller-argument mapping and preservation of supplied children’s origins. This needs facade work, not an engine change.

6. **Remove “unless the first two are one block” from §2.4.** Making both preceding blocks sticky also groups them with the following block, subject to available space; the implementation explicitly handles consecutive sticky blocks ([flow_distribute:473](/Users/dii/git/typst.mbt/layout/flow_distribute.mbt:473)).

Optional changes:

1. Separate measured size from region size, or define what `Size.baseline` means in `Layout`: its engine dictionary contains only width and height.
2. Specify `Lines`’ empty/trailing-line handling, tab stops across spans, and whether ordinary wrapping/hyphenation remains enabled.
