# Agent guide

- This is a MoonBit port of Typst; upstream sources live in `.repos/typst`
  (pinned by `UPSTREAM_REV`). Port faithfully: keep upstream structure,
  names, comments and error messages so diffs stay reviewable.
- Correctness is measured differentially: `scripts/goldens.sh <stage>`
  dumps upstream outputs; `moon run tests/runner --target native -- <stage>`
  must not regress.
- All syntax offsets/lengths are UTF-8 byte based even though text is
  stored as MoonBit `String` (UTF-16). Use `utf8_len`/`utf8_slice`.
- Unicode properties must come from `unicode/` (generated by
  `oracle/src/bin/gen_unicode.rs`), never hand-written approximations.
- Before committing: `moon fmt && moon info && moon check`, run the runner.
