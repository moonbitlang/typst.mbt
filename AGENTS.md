# Agent guide

## Porting Typst

- Use `.repos/typst` at `UPSTREAM_REV` as the reference (`scripts/upstream.sh`
  fetches it). Keep upstream structure, names and useful comments. Match
  diagnostics, hints and reprs byte for byte; read the upstream code rather
  than guessing. Use `library/rust_fmt.mbt` for Rust-style number formatting.
- Syntax spans use UTF-8 byte offsets and lengths, even though MoonBit
  `String` is UTF-16. Use `utf8_len` and `utf8_slice`. Get Unicode properties
  from the generated tables in `unicode/`, not hand-written approximations.
- `Source` and `Lines` are persistent. Keep the value returned by `edit` or
  `replace`. Only write to a syntax node you own; copy the affected path and
  preserve shared nodes and their spans. `synthesize` and `synthesize_ranges`
  are for fresh trees, not nodes in a `Source`. See the contract in
  [syntax/node.mbt](syntax/node.mbt) and the `reparse` stage.
- Frames are mutable with copy-on-write items. Translate upstream
  `frame.clone()` literally and do not reuse a frame after moving it into a
  group or fragment. `Regions` are immutable (`regions = regions.next()`).
- Mark values shared (`Value::shared`) where upstream clones them out of
  long-lived storage; a subsequent mutation must not change the stored value.
  For a new storage boundary, add a probe to `scripts/sharing_probes.py`.
- MoonBit sorts strings by length first; use `compare_str` for Rust `str`
  ordering. Preserve input order for distinguishable ties where upstream
  uses stable sorting. Only the sign of `Compare::compare` is guaranteed.
- Use `guard!` for broken invariants and `errdefer` for cleanup on error.
  Match upstream's fallibility: plain returns do not `raise`; `Result`
  returns and uniform fallible signatures keep `raise`.

## MoonBit checks and tests

- Supported targets: native and wasm. Before committing, run `moon fmt`
  and `moon check --target <target> --deny-warn` for both targets. Fix warnings
  at the source. If upstream parity requires the code, use a declaration-level
  `#warnings("-<name>")` with an upstream reference. Package-wide warning
  suppression is a last resort. Check for a missing port before suppressing
  an unused item or error type.
- After each public trait impl or public type's derive, declare its methods
  with `pub extend T with Trait::{...}`. Expose only intended methods of
  the type; otherwise put `#deprecated(...)` then `#doc(hidden)` on the
  extension and call `Trait::method(x)`. Use one extension per trait, in
  derive order, and the import alias for traits from other packages. If
  names collide, prefer an inherent method, then the trait called as a type
  method upstream, then a port trait over a core trait, then file order.
  Note the omission by the impl. In `doc/`, `ToValue`, `IntoContent` and
  `@debug.Debug` stay trait calls. See `scripts/promotions.py` for bulk updates.
- Run focused tests with `moon test <path> --target native -j16`. For a
  behavior change, use the relevant differential stage:
  ```sh
  scripts/goldens.sh <stage>
  moon run tests/runner --target native -- <stage> [filter]
  ```
  Use `--release` before `--` for long sweeps. The runner can exit zero
  even with failures: read its summary, or use `scripts/ci/stages.py <stage>`
  with a release runner. [scripts/ci/stages.tsv](scripts/ci/stages.tsv) lists
  stages and expected counts; update counts when the corpus changes. Do not
  change fixtures or widen known failures to hide a port regression. Use
  `scripts/ci/data.sh` to prepare test data; the hayro oracles can silently
  skip without `target/hayro` and `target/devassets`.

## Generated code

Never edit `*_gen.mbt` by hand. Fix the generator and rerun it, including
when resolving merge conflicts or fixing warnings in generated output.

| Change | Entry point |
| --- | --- |
| Typst native function | Implement `impl_<key>` from `library/funcs_todo_gen.mbt` in a handwritten file; run `python3 scripts/funcgen.py`. Keep nontrivial defaults in `impl_<key>__<param>_default()` and constants in `impl_<type>_const_<name>()`. |
| Typst element | Use the hooks in `library/elems_todo_gen.mbt` and run `scripts/elemgen.py`. Provide field output or equality hooks where storage does not match upstream's exposed value or equality. Use typed views generated by `scripts/viewgen.py` in ported code. |
| Typst native type | Run `scripts/typegen.py` for descriptors. After porting `Reflect`/`FromValue`/`IntoValue`, update `TYPEMAP` in `scripts/typemap.py` and rerun `elemgen.py`, `funcgen.py` and `viewgen.py`. |
| Unicode and line breaking | `oracle/src/bin/gen_unicode.rs` and `scripts/gen_breaking.sh`. |
| EDSL constructors and translator signatures | `scripts/docgen.py`. |

Keep large immutable tables static (`ReadOnlyArray` literals with static
entries). Use `StringView` and `ArrayView` to avoid copies in hot paths.
Measure performance changes using [bench/README.md](bench/README.md); use
`scripts/alloc_sites.py` for native allocation profiles.

## When touching a subsystem

- **Incremental compilation:** Read [the design](docs/incremental-design.md)
  and [recompile tests](tests/recompile/README.md). Use `TrackedWorld` for
  engine reads. A kept result must match its arguments and validated reads,
  replay its effects, and not expose mutable objects owned by the cache.
  Preserve upstream module equality and eviction behavior. Update the design
  inventory for new state. Run `scripts/tracked_world_check.py` after
  changing world access; use `--check-reads` and the `recompile` mutation
  checks after changing recorded reads, store keys, validation or lifetimes.
- **Fonts and shaping:** Use `font`, `shape` and `shape-hb` as appropriate.
  Copy `GlyphInfo` and `GlyphPosition` where Rust copies. Keep EDSL fonts out
  of CLI/kit worlds and out of implicit fallback; see
  [doc/fonts/fonts.mbt](doc/fonts/fonts.mbt) and [doc/sans_test.mbt](doc/sans_test.mbt).
- **Math and SIMD:** Use the matching `libm` ports for Typst's `libm` calls;
  use `@libm.f64_cbrt` where upstream calls Rust's platform `f64::cbrt`.
  v128 kernels must match the scalar path bit for bit. Prove unchecked
  ranges without overflow and fall back on aliasing or unmet lane contracts.
  Preserve upstream rounding and NaN behavior; do not substitute relaxed
  float operations. Test both paths and measure on native and wasm.
- **PNG decoding:** Preserve upstream's error ordering and treatment of
  damaged chunks. See [the PNG oracle](codecs/png_oracle_test.mbt) and
  `scripts/goldens.sh raster`.
- **Layout and SVG export:** Use `paged` for frames and `svg`/`svg-replay`
  for SVG. Replay uses upstream frames to isolate export from layout.
- **PDF export:** Use `pdf-semantic`, `pdf-semantic-replay` and `pdftags`.
  Upstream PDF byte equality is not the goal. Keep Typst semantics in `pdf/`
  and generic exporter behavior in pdflite; `@export.Memo` keeps reuse in
  the host, not in pdflite.
- **CLI and watch:** Keep OS access in the kit/platform layer or its existing
  `async/fs` integration, not the synchronous engine. See the bridge
  contract in [kit/watcher/notify.mbt](kit/watcher/notify.mbt). Run
  `scripts/watch_check.py` on native and wasm for watch/compile-loop changes;
  use the `recompile` stage for cache correctness.
- **EDSL:** `doc/` uses public engine APIs; the engine does not depend on it.
  See [design](docs/edsl-design.md), [review](docs/edsl-review.md),
  [guide](docs/edsl-guide.md), and [translator design](docs/edsl-convert.md).
  Read [doc/kit/kit.mbt](doc/kit/kit.mbt) before adding composites. Use the
  `edsl` stage to compare with Typst twins. After editing `doc/review_page/`,
  regenerate with `scripts/gen_review_page.py`, then run
  `node scripts/review_page_check.mjs preview.html` on a generated preview.
  After editing the guide or its examples, run `scripts/edsl_guide_check.py`.
- **Real packages:** Follow [tests/packages/README.md](tests/packages/README.md).
  Pin archives and their transitive dependencies; reduce mismatches to a
  package-free regression case rather than editing the document to pass.

## Publishing

Dependencies do not run `pre-build` steps. Ship the generated font data for
both `typst_assets/fonts` and `doc/fonts` in the package zip. Run
[scripts/ci/package_smoke.sh](scripts/ci/package_smoke.sh), and verify a
release as a registry dependency on native and wasm, not just as a root
module or workspace member. See [.github/workflows/ci.yml](.github/workflows/ci.yml)
for the CI jobs and `scripts/ci/known_failures/` for documented platform
differences.
